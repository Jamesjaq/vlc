# VLC Infinity Enhanced - Quick Start (Pre-Configured)

**No API key setup needed!** Your TMDB API key is already pre-configured. Just install and start streaming.

---

## Installation (2 Minutes)

### Windows
1. Download `vlc-infinity-enhanced.lua` from GitHub
2. Copy to: `C:\Program Files\VideoLAN\VLC\lua\extensions\` or `%APPDATA%\vlc\lua\extensions\`
3. Restart VLC
4. Done!

### macOS
1. Download `vlc-infinity-enhanced.lua` from GitHub
2. Copy to: `~/Library/Application Support/org.videolan.vlc/lua/extensions/`
3. Restart VLC
4. Done!

### Linux
1. Download `vlc-infinity-enhanced.lua` from GitHub
2. Run:
   ```bash
   mkdir -p ~/.local/share/vlc/lua/extensions/
   cp vlc-infinity-enhanced.lua ~/.local/share/vlc/lua/extensions/
   ```
3. Restart VLC
4. Done!

---

## First Use (1 Minute)

1. **Open VLC Media Player**
2. **Click `View` menu** → **`VLC Infinity Enhanced`**
3. **Click `Search Movies`**
4. **Type a movie name** (e.g., "The Matrix", "Inception", "Avatar")
5. **Click `Search`**
6. **Select a movie** from results
7. **Click `Play Movie`**
8. **Enjoy!** 🎬

## Streaming Sources

VLC Infinity automatically tries these sources in order:

1. **VidSrc** - Primary source (most reliable)
2. **2embed** - Fallback source
3. **RapidCloud** - Additional fallback

If one source fails, it automatically tries the next one.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| **Movie won't play** | Try a different movie; stream may be unavailable |
| **No search results** | Check spelling; try different movie title |
| **Slow streaming** | Increase network caching in VLC Preferences |
| **Region blocked** | Go to Settings and change region code |
| **Favorites not saving** | Restart VLC and try again |

## Tips & Tricks

✅ **Search Tips:**
- Use just the movie name (e.g., "Matrix" instead of "The Matrix")
- Include year for older movies (e.g., "Jaws 1975")
- Try different spellings if no results

✅ **Playback Tips:**
- Press `F` for fullscreen
- Press `Spacebar` to pause/play
- Use volume slider for sound control
- Drag progress bar to seek

✅ **Performance Tips:**
- Close other apps to free up bandwidth
- Increase VLC's network caching for smoother playback
- Use wired internet for better speeds
