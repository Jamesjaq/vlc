# VLC Infinity Quick Start Guide

Get up and running with VLC Infinity in 5 minutes!

---

## 1. Installation (2 minutes)

### Windows
1. Download `vlc-infinity.lua` from [GitHub](https://github.com/Jamesjaq/vlc/tree/vlc-infinity/share/lua/extensions)
2. Copy it to: `C:\Program Files\VideoLAN\VLC\lua\extensions\` or `%APPDATA%\vlc\lua\extensions\`
3. Restart VLC

### macOS
1. Download `vlc-infinity.lua` from [GitHub](https://github.com/Jamesjaq/vlc/tree/vlc-infinity/share/lua/extensions)
2. Copy it to: `~/Library/Application Support/org.videolan.vlc/lua/extensions/`
3. Restart VLC

### Linux
1. Download `vlc-infinity.lua` from [GitHub](https://github.com/Jamesjaq/vlc/tree/vlc-infinity/share/lua/extensions)
2. Run:
   ```bash
   mkdir -p ~/.local/share/vlc/lua/extensions/
   cp vlc-infinity.lua ~/.local/share/vlc/lua/extensions/
   ```
3. Restart VLC

---

## 2. First Launch (1 minute)

1. **Open VLC Media Player**
2. **Click `View` menu** → **`VLC Infinity`**
3. **The VLC Infinity dialog appears!**

---

## 3. Browse Channels (1 minute)

1. **Click `Browse Channels`**
2. **Select a country** from the dropdown (e.g., "United States")
3. **Select a category** from the dropdown (e.g., "Sports")
4. **Select a channel** from the list
5. **Click `Play`** to start watching!

---

## 4. Browse Movies (1 minute)

1. **Click `Browse Movies`**
2. **Search for a movie** (e.g., type "Chaplin")
3. **Click `Search`**
4. **Select a genre** (optional)
5. **Select a movie** from the list
6. **Click `Play Movie`** to start watching!

---

## 5. Save Favorites

1. **While browsing channels**, select a channel you like
2. **Click `Add to Favorites`**
3. **Next time**, click `Favorites` from the main menu to quickly access your saved channels

---

## Common Tasks

### Search for a specific channel
1. Click `Browse Channels`
2. Type the channel name in the search box (e.g., "BBC")
3. Click `Search`

### Filter by country
1. Click `Browse Channels`
2. Select a country from the dropdown
3. Browse the filtered list

### Find movies by genre
1. Click `Browse Movies`
2. Search for a movie
3. Select a genre from the dropdown to filter results

### Replay something you watched
1. Click `History`
2. Select an item from your watch history
3. Click `Play from History`

---

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Extension not in View menu | Ensure `vlc-infinity.lua` is in the correct extensions folder and VLC is restarted |
| Stream won't play | Try a different channel; the stream may be offline |
| No search results | Check your internet connection and try a different search term |
| Favorites not saving | Restart VLC and ensure you have write permissions to the VLC config folder |
